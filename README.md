# Valut — VALORANT Skin Catalog

Niezależny katalog fanowski tworzony przez Adama.

## Uruchomienie
Strona jest statyczna. Otwórz `index.html` w przeglądarce albo opublikuj repozytorium przez GitHub Pages.

## Publikacja przez GitHub Pages
1. Otwórz repozytorium `valut` na GitHubie.
2. Wejdź w **Settings → Pages**.
3. W sekcji **Build and deployment** wybierz **Deploy from a branch**.
4. Wybierz gałąź **main** i folder **/(root)**, a następnie kliknij **Save**.
5. Po zakończeniu publikacji strona będzie dostępna pod adresem `https://orzech21373-cell.github.io/valut/`.

## Funkcje
- Katalog skinów ładowany z publicznego API VALORANT-API.
- Wyszukiwanie i filtrowanie według broni.
- Sortowanie i lokalna lista ulubionych.
- Responsywny wygląd dla telefonów i komputerów.
